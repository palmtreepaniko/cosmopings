Engine Workflow

How Cosmopings Dispatches Updates

01
Atom XML Ingest
Pulls high-frequency RSS atom feeds every 300 seconds with zero YouTube Data API quota cost.
02
JSON State Filter
Verifies against posted.json to ensure zero duplicated pings across container restarts.
03
Shorts Duration Shield
Parses ISO 8601 duration; discards YouTube Shorts under 60 seconds and historical backlogs older than 24h.
04
Smart Classifier
Inspects hashtags (#miracle_melody vs #miracle_live) to route to dedicated Discord channels.
05
Discord Gateway
Dispatches dynamic localized relative timestamps (<t:unix:R>) for worldwide viewers.
