Engine Mechanics & Filter Rules

bot.py logic breakdown

1. Quota-Optimized Ingestion

Avoids burning through YouTube Data API limits. Regularly scrapes the zero-quota RSS XML Atom feed every 300 seconds, only utilizing the heavy search().list API endpoint every 6 cycles (~30 minutes) specifically for upcoming scheduled events.

CHECK_INTERVAL = 300
UPCOMING_CHECK_EVERY = 6
URL = f"https://www.youtube.com/feeds/videos.xml?channel_id={CHANNEL_ID}"

2. Shorts Duration Shield

Eliminates notification spam from vertical YouTube Shorts. Parses ISO 8601 duration strings and discards content under 60 seconds with #shorts tags. Backlog uploads older than 24h are safely dropped.

match = re.match(r"PT(?:(\d+)H)?(?:(\d+)M)?(?:(\d+)S)?", duration)
if duration_seconds <= 60 or "#shorts" in text:
    posted.append(video_id); continue

3. Hashtag Heuristics

Accurately differentiates covers from gaming and chatting broadcasts by analyzing title strings and description tags. Dispatches covers to COVER_CHANNEL_ID and streams to LIVE_CHANNEL_ID.

COVER_HASHTAGS = ["miracle_melody"]
LIVE_HASHTAGS = ["miracle_live"]
COVER_KEYWORDS = ["cover"]
LIVE_KEYWORDS = ["live", "stream"]
