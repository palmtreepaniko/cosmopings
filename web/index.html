Core Capabilities

Engineered for Accuracy

Cosmopings solves common YouTube notification pain points: missed streams, delayed alerts, Shorts spam, and quota exhaustion.

Dual-Engine Polling

Combines high-frequency YouTube RSS atom feeds with smart YouTube Data API v3 quota caching. Catches publications instantly without hitting API rate limits.

Smart Content Classifier

Automatically separates music covers from gaming/chat livestreams using custom hashtag detection (#miracle_melody vs #miracle_live) and routes them to their dedicated Discord channels.

Dynamic Relative Timestamps

Posts upcoming premieres with Discord native <t:unix:R> syntax, meaning international viewers see the countdown dynamically in their exact local timezone.

Shorts & Stale Video Shield

Parses ISO 8601 durations and tags to eliminate unwanted YouTube Shorts notifications. Stale videos older than 24 hours are safely suppressed during cold starts.

Stateful JSON Deduplication

Maintains persistent posted.json and scheduled.json databases. Survives container restarts without re-pinging your community.

Embedded Web Server

Native asynchronous aiohttp microservice listening on port 25888 for bot-hosting.cloud proxy routing, keep-alive pings, and real-time JSON status APIs.

Under the Hood

Data Pipeline Architecture

How Cosmopings ingests, evaluates, classifies, and broadcasts updates asynchronously.

1
Ingest & Sync
Fast XML RSS polling every 300s + Scheduled YouTube v3 Search API every 6 cycles.
2
Deduplication
Validates against posted.json and discards previously announced video IDs.
3
Filter Shield
Parses ISO 8601 duration; discards YouTube Shorts & backlog items older than 24h.
4
Classifier
Matches hashtags & keywords to route to Cover vs. Livestream Discord channels.
5
Broadcast
Constructs dynamic Discord message with timestamp tags and dispatches via Discord Gateway.
