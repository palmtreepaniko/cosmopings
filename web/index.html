The Engineering Challenge

Problem formulation & solution design

The Architectural Problem

Standard Discord bots polling YouTube rely exclusively on public webhook services or the YouTube Data API v3 search().list endpoint. In active fan communities, this leads to two critical failures:

1. Quota Exhaustion: YouTube's search().list endpoint consumes 100 quota units per call, causing typical bots to crash from rate limits within 24–48 hours.

2. Noise & Shorts Spam: Generic bots ping members whenever vertical YouTube Shorts (under 60s) or old backlog videos are uploaded, causing member alert fatigue.

The Cosmopings Solution

Cosmopings replaces blunt API polling with a dual-engine ingestion architecture:

• Zero-Quota Ingest: Scrapes the XML Atom RSS feed every 300 seconds for instant upload detection without consuming any API units.

• ISO 8601 Filter Shield: Parses video duration strings (`PT<60S`) to cleanly suppress YouTube Shorts, while matching specific community hashtags (#miracle_melody vs #miracle_live) to route covers and broadcasts to separate channels.

Duration Parser Python 
def parse_iso8601_duration(duration_str):
    if not duration_str: return None
    match = re.match(
        r"PT(?:(\d+)H)?(?:(\d+)M)?(?:(\d+)S)?", 
        duration_str
    )
    if not match: return None
    h, m, s = (int(g) if g else 0 for g in match.groups())
    return h * 3600 + m * 60 + s
Shorts Detection Python 
def is_probable_short(title, desc, duration_sec):
    text = f"{title or ''} {desc or ''}".lower()
    if any(tag in text for tag in ["#shorts", "#short"]):
        return True
    if duration_sec and 0 < duration_sec <= 60:
        return True
    return False
