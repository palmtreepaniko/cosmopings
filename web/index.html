GOT QUESTIONS?

A few things
you might be wondering.

What exactly does Cosmopings do?

It keeps an eye on a YouTube channel and lets your Discord server know whenever there's a new cover or livestream. You can even send each type of update to its own channel, so everything stays organized.

Does the status panel show the actual bot status?

Yep! It checks the bot through its hosting service. If the server doesn't respond, the panel will say the status is unavailable instead of pretending everything is fine.

Is the bot hosted on this website?

Nope. The website and the bot are hosted separately. The website runs on GitHub Pages, while the bot has its own hosting service.

Can I run my own copy?

Of course! The source code is public, so feel free to clone the repository, set it up for your own Discord server, and make whatever changes you need.

How does it know whether something is a cover or a livestream?

It checks things like keywords, hashtags, and YouTube's livestream information to figure out what kind of content was posted. That way, each update goes where it's supposed to.

Found a bug or need help?

You can reach me on Discord: palmtree_panik. Feel free to get in touch if something isn't working or you have a question!
